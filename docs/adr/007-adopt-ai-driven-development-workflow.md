# ADR-007 - Adopt AI-Driven Development Workflow

## Status

Accepted

## Date

2026-06-10

## Decision

Formalize a structured AI-assisted development workflow.

## Context

The project increasingly relies on AI assistance.

Unstructured prompting leads to:

- inconsistent results
- repeated misunderstandings
- reduced maintainability

A repeatable workflow is required.

## Alternatives Considered

### Ad-Hoc Prompting

#### Pros

- quick to start

#### Cons

- inconsistent quality
- poor reproducibility

### Structured Workflow

#### Pros

- predictable outcomes
- measurable quality
- improved collaboration

#### Cons

- initial setup effort

## Decision Outcome

Adopt the following workflow:

```text
Roadmap
    ↓
Task
    ↓
Plan
    ↓
Implementation
    ↓
Quality Gates
    ↓
Retrospective
```

Supported by:

- rules
- templates
- architecture documentation
- metrics

## Consequences

### Positive

- reproducible process
- measurable improvements
- easier onboarding

### Negative

- more documentation

## Follow-up Decisions

- metrics generator
- AI dashboard
- project analytics
